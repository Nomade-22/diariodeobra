# Diário de Obra

Sistema interno de controle de atividades de obra da Multprest.

## Stack

- Next.js / React
- PostgreSQL / Neon
- Better Auth
- Tailwind CSS

## Funcionalidades

- Novo registro de atividade
- Histórico de registros
- Cadastro de funcionários
- Cadastro de clientes
- Gestão de usuários
- Autenticação
- Upload de fotos
- Integração com ordens de serviço

## Publicação

O código-fonte fica neste repositório GitHub. Para produção, a aplicação deve ser publicada em uma plataforma compatível com Next.js, como Vercel, e conectada a um banco PostgreSQL/Neon.

As variáveis necessárias estão documentadas em `.env.example`.

## Segurança

O repositório não contém o dump de dados reais do banco nem arquivos `.env` com credenciais.
